# Gharpayy CRM MVP

🔗 **Live Demo:** https://graphy-3dse.vercel.app/

A lead management system for PG accommodation leads.

---

## Features

* Lead capture
* Pipeline management
* Drag and drop stages
* Visit scheduling
* Follow-up reminders
* Dashboard analytics

---

## Tech Stack

**Frontend:** React + Tailwind
**Backend:** Node.js + Express
**Database:** MongoDB Atlas

---

## Run Locally

### Backend

```
npm install
node server.js
```

### Frontend

```
npm install
npm run dev
```
